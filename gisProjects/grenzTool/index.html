Tool für das einfache Erstellen von Länderpolygonen

In so manchen Design-Projekten benötigt man als Shape die Umrisse von Ländern. Um eine sipmple Bezugsquelle zu generieren, habe ich dieses Tool erstellt.

Einerseits können die Länderpolygone als SVG abgespeichert werden, um die in Shapes in Grafik-Tools weiterzubearbeiten. Andererseits können sie als GeoJSON abgespeichert werden, was das Weiterbearbeiten in einem GIS-Kontext ermöglicht.

Verschiedene Designs, unterschiedliche geographische Regionen und verschiedene Ländergrössen verlangen nach unterschiedlichen Kartenprojektionen, weshalb zwischen acht Projektionen gewählt werden kann, die weiter unten beschrieben werden.

🚐 Built with solar power somewhere in Europe ☀️
